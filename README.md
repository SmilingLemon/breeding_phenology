# Breeding phenology

Data and R scripts accompanying analyses of breeding phenology in ground tits.

## Files

| Script | Contents |
| --- | --- |
| `01_climate_windows.R` | Climate-window analysis and Figure 1a-e |
| `02_individual_predictors.R` | Individual-level predictors of breeding time and Figure 1f |
| `03_animal_model_and_selection.R` | Random-regression animal model, selection analyses and Figure 2 |
| `04_future_projections.R` | Future warming, adaptive capacity and Figure 3a-c |
| `05_pedigree.R` | Table S1 pedigree summaries and annual climate trends |
| `plot_style_publication.R` | Shared plotting functions |

The `data/` directory contains:

- `dxfamily.csv`: breeding records and associated predictors.
- `ped.csv`: pedigree identifiers and parental relationships (`animal`, `dam`, `sire`).
- `pedigree_subset.csv`: `animal` IDs identifying the phenotyped pedigree subset, including family-related individuals rather than only breeding females.
- `dangxiong_monthly.csv`: monthly station climate data.

## Requirements

R and the following packages are required:

```r
install.packages(c(
  "dplyr", "tidyr", "ggplot2", "scales", "climwin", "lme4",
  "MCMCglmm", "coda", "terra", "stringr", "purrr", "cowplot"
))
```

WorldClim rasters are not included. Obtain the historical monthly climate, current-climate minimum temperature and CMIP6 minimum-temperature projections from WorldClim. Set the raster directories specified in scripts 01, 04 and 05 to match their local locations. Raster periods, resolutions and filename patterns are specified in the scripts.

## Running the analyses

Set the R working directory to the repository root, containing the scripts and `data/`. Run scripts 01-05 in numerical order, for example:

```r
source("01_climate_windows.R")
```

Script 04 uses the model and evolutionary-response samples generated by script 03. Shared plotting functions are loaded by the analysis scripts. Tables, model objects and figures are written to `results/`.

The scripts include model fitting and climate-window randomizations, which may take substantial time. Fresh stochastic runs may produce small numerical differences.
